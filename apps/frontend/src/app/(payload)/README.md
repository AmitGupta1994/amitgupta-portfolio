# Generated Payload routes

These files are generated by Payload and re-export its admin UI (`/admin`) and API
(`/api/**`). They live here only because Next.js serves routes from `src/app` — all
real CMS code is in `src/cms/payload`.

Don't hand-edit them. Regenerate the import map with:

```bash
npm run generate:importmap -w frontend
```

Replacing Payload with another CMS means deleting this folder and `src/cms/payload`,
then pointing `src/content/index.ts` at the new adapter.
